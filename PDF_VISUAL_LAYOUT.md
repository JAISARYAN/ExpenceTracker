## Color Palette

### Summary Cards
```
┌─────────────┐
│   INCOME    │  Background: #22C55E (Emerald Green)
│  ₹ 50,000   │  Text: White (positive, money earned)
└─────────────┘

┌─────────────┐
│  EXPENSE    │  Background: #EF4444 (Red)
│  ₹ 35,000   │  Text: White (important attention)
└─────────────┘

┌─────────────┐
│  BALANCE    │  Background: #3B82F6 (Blue)
│  ₹ 15,000   │  Text: Dynamic (green if positive, red if negative)
└─────────────┘
```

### Table Elements
```
Header: #6366F1 (Indigo) with white text - professional look
Row 1:  White background
Row 2:  #F8F8F8 (Light gray) - easy on eyes
Row 3:  White background
...alternating pattern

Borders: #C8C8C8 (Light gray) - subtle separation
```

### Text Elements
```
Title:           24pt, Bold, White on Dark
Section Headers: 12pt, Bold, Black
Table Headers:   Bold, White on Indigo
Table Data:      9pt, Black
Type Labels:     Green (#22C55E) for Income
                 Red (#EF4444) for Expense
Footer:          8pt, Gray (#646464), Italic
```

## Print-Friendly Features

✅ **Optimized for A4 Paper**
- Proper margins (15mm all sides)
- Single-column layout
- Professional spacing

✅ **Optimal Print Settings**
- Print at 100% scale (not "Fit to page")
- Use color printing for best appearance
- Greyscale friendly (colors remain distinct)

✅ **Digital/Email Sharing**
- Readable on all PDF viewers
- Zoomable for mobile viewing
- Professional appearance in email

## Data Organization

### Logical Flow
```
1. Visual Summary (Cards)
   ↓ Quick financial overview
2. Category Analysis (Table)
   ↓ Where money went/came from
3. Detail Level (Transactions)
   ↓ Complete transaction history
4. Insights (Statistics)
   ↓ Key financial metrics
5. Attribution (Footer)
   ↓ Report metadata
```

## File Naming Convention

```
FinTrack_Report_[PERIOD]_[DATE].pdf

Examples:
├── FinTrack_Report_Today_2026-02-24.pdf
├── FinTrack_Report_Last_7_Days_2026-02-24.pdf
├── FinTrack_Report_Last_30_Days_2026-02-24.pdf
└── FinTrack_Report_All_Time_2026-02-24.pdf
```

## Information Hierarchy

```
Level 1 (Immediate Focus)
├── Summary Cards (Income/Expense/Balance)
│   └── Large numbers, colorful layout
│
Level 2 (Quick Analysis)
├── Category Breakdown
│   └── What categories have most activity
│
Level 3 (Detailed Review)
├── Transaction Details
│   └── Individual entry information
│
Level 4 (Analysis)
├── Summary Statistics
│   └── Calculated insights and ratios
│
Level 5 (Reference)
└── User & Timestamp Info
    └── Report metadata
```
